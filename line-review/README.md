# Нейросеть разбирает строчки

Формат «разбор как шахматная партия», применённый к песне. Каждая строчка появляется карточкой с вердиктом: «Блестяще!!», «Лучший ход», «Отлично!», «Хорошо», «Неточность?!», «Ошибка?». Шкала оценки качается между «трек» и «хейтеры», доска на фоне пульсирует в бит. В конце экран «Партия окончена» с точностью, разбивкой по оценкам и лучшим ходом.

Первый выпуск: VILLIAN & madk1d «ДИНАСТИЯ». Это последняя строчка припева и весь второй куплет, 13 ходов, точность 72%, 46 с. На экран попадают только короткие цитаты, мат закрыт звёздочками.

| Файл | Роль |
|---|---|
| `review.js` | Оценки и короткие цитаты. Строчки привязаны к тактам: после дропа 28 строк на 56 тактов, по два такта на строку |
| `render.html` | Карточки, вердикты, шкала, итоговый экран, плашка Domino Team |
| `build.js` | Сетка битов из `../beat-bounce/beats.json`, вырез трека, рендер |

```bash
node build.js --track династия.mp3     # → line-review.mp4 (видео с треком в репозиторий не кладётся)
node build.js --preview 1,10,44
```
